# 📊 Stock Clustering Analysis (Indonesia)
Analisis clustering 27 saham Indonesia menggunakan HDBSCAN, DBSCAN, dan GMM berbasis return, volatilitas, Sharpe ratio, dan beta.

## 🚀 Cara Menjalankan Lokal
1. `python -m venv venv && source venv/bin/activate`
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

## ☁️ Deploy ke Streamlit Community Cloud
1. Push repository ini ke GitHub.
2. Kunjungi [share.streamlit.io](https://share.streamlit.io)
3. Hubungkan GitHub & pilih repo ini.
4. Streamlit akan otomatis mendeteksi `app.py` dan `requirements.txt`.
